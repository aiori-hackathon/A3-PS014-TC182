## 3. Project Overview

Internet speed alone does not always reflect the quality of a connection. Latency, jitter, packet loss, and connection stability can also affect the user experience.

Our proposed solution focuses on comparing internet quality across verified access mediums so users can better understand the performance and reliability of their connections.

## 4. Problem Statement

Users need a meaningful way to compare internet connectivity across different access mediums. Comparing only advertised speeds or a single speed-test result may not provide a complete picture of real-world network performance.

## 5. Proposed Solution

The project aims to provide a structured comparison of internet quality using relevant network performance indicators and verified information about the access medium.

The proposed approach focuses on:
- Comparing relevant network performance metrics.
- Identifying differences in connection quality and stability.
- Presenting comparison results in an understandable format.
- Helping users make better-informed connectivity decisions.

## 6. Key Performance Indicators

The proposed comparison may include:

- **Download and upload speed:** Data transfer performance.
- **Latency:** Time taken for data to travel across the network.
- **Jitter:** Variation in latency.
- **Packet loss:** Percentage of packets that fail to reach their destination.
- **Connection stability:** Consistency of performance over time.

*Final metrics will depend on the implemented measurement and verification methodology.*

## 7. Expected Outcome

The expected outcome is a clear and useful comparison of internet quality across verified access mediums, helping users understand network performance beyond download speed alone.
